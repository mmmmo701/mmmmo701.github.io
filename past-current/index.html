Cutland, Computability, An introduction to recursive function theory
When taking 15-251 (Great Ideas in Theoretical Computer Science), I was fascinated by how there is a complete different world of computability theory besides what's in Sipser. Therefore, I started reading Soare's Turing Computability, Theory and Applications. However, this book is extremely difficult as it is very dense and doesn't use the notations we typically use. For example, it uses $\omega$ instead of $\mathbb{N}$ for natural numbers. Therefore, I decided to switch to Cutland's Computability, An introduction to recursive function theory.
Decision Making under Imperfect Recall: Algorithms and Benchmarks
I'm interested in Algorithmic Game Theory, so this is a paper I found that I really like. I've been trying to find time to read it when I don't have a lot of homework. The paper is here. It talks about games with Imperfect Recall: players will sometimes forget things. This model is important as it's hard to store everything you know when playing a game, and the imperfect recall model can also simulate team games with limited communication.
